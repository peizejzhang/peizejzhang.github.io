## [Cocoa Price Forecasting with SARIMA and GAM](https://github.com/peizejzhang/Time-Series-Forecasting)

A comparative time-series forecasting project that models cocoa prices using SARIMA and Generalized Additive Models (GAM). The analysis incorporates historical cocoa prices, weather conditions in Ghana, and exchange-rate data.

- **Methods:** ARIMA, SARIMA, GAM
- **Language:** R
- **Result:** The GAM model using time and exchange-rate features achieved a test RMSE of **1430.807**, outperforming the ARIMA baseline.
- **Deliverables:** Reproducible R Markdown analyses, datasets, experiment results, and a final research report.

[View repository](https://github.com/peizejzhang/Time-Series-Forecasting) · [Read report](https://github.com/peizejzhang/Time-Series-Forecasting/blob/main/STA457_Final_Project.pdf)

## [YouTube Spam Classification](https://github.com/peizejzhang/youtube-spam-classification)

A machine-learning project for classifying YouTube comments as spam or non-spam. The project evaluates predictive performance together with inference latency to support practical model selection.

- **Methods:** Bag-of-Words, TF-IDF, n-grams, Naive Bayes, SVM, and Random Forest
- **Language:** Python
- **Evaluation:** Stratified 10-fold cross-validation using F1 score and inference time
- **Result:** Random Forest with 5-gram TF-IDF achieved the highest F1 score of **0.962**.
- **Contribution:** Proposed and developed the accuracy–latency trade-off analysis for identifying suitable model configurations.

[View repository](https://github.com/peizejzhang/youtube-spam-classification) · [Read paper](https://github.com/peizejzhang/youtube-spam-classification/blob/main/Final_Paper.pdf)
